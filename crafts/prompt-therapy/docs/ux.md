# Prompt Therapy v1.0 — conversation design

Status: draft for the operator's acceptance (d-work #1, P1). Reads with `prd.md`.

## The page
One chat column. Above it, always visible: **"Not therapy, not professional advice."** A link reads "What happens to what
I write?" and opens the retention text from the PRD in plain words.

## The walk, turn by turn
| step | the agent says (in substance) | the user can |
|---|---|---|
| greet | what this is and is not; "Tell me what you saw an AI agent do." | write freely |
| describe | reflects it back in one sentence; asks if that is right | confirm or correct |
| match | "It sounds like one of these:" two or three canon entries in their own wording, plus "none of these" | pick one, or none |
| walk | "Why do you think that happened? Or could it be that…?" one cause from the tree, as a question | pick it, reject it, or say their own why |
| anchor | names where the whys led, in the tree's words, and asks whether it rings true | agree, or go back a level |
| helps | what the dyad does about it, with its source, or "nothing serves this yet" | ask a question, or move on |
| consent | "May I keep what you saw, in your words and without your name, so it can help improve this?" | yes, no |
| close | thanks; what was kept, or that nothing was; how to delete it | leave, or ask to delete |

## Rules of voice
- One question per turn. Never more than three options.
- A cause is always a question, never a verdict. The user's own why outranks every hypothesis.
- Short sentences, plain words, no jargon from the corpus.
- It never names a person, even one the user named, and it never says what the user feels.
- "None of these" is always offered; matching nothing is a valid end, and the walk still reaches consent.

## Deletion
At any time the user can write "delete" or press a button: the conversation is deleted at once, and the agent says so.
After a kept symptom, the close message carries a deletion code; using it deletes the kept record.
